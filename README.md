# 浙江大学 MBA｜战略领导力期末复习站

这是一个独立的 MBA 课程复习网站，与工程课程仓库分开维护。

## 考试形式

根据课程复习资料，按以下形式准备：

- 论述题：1 道
- 案例分析题：1 道
- 不设置选择题练习模块

## 复习内容

- 核心概念与教材第 1、2、3、4、6 章框架
- 战略领导力四层次、制度设计、文化定位、系统思维与信任
- 思龙智能案例分析与答题思路
- 论述题模拟、案例分析模拟及独立写作草稿
- 记忆闪卡与考前速记
- 学习进度与草稿保存在当前浏览器

## 在线访问

https://monicalee62556-dotcom.github.io/mba-strategy-leadership/

## 发布方式

进入仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存即可。

网站入口为根目录的 `index.html`，无需构建步骤或外部依赖。学习记录和草稿保存在当前浏览器的本地存储中。
