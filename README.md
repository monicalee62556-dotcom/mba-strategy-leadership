# 浙江大学 MBA｜战略领导力期末复习站

这是一个独立的 MBA 课程复习网站，与工程课程仓库分开维护。

## 考试形式

根据课程复习资料和助教确认的信息，按以下形式准备：

- 论述题：1 道
- 案例分析题：1 道
- 不设置选择题练习模块
- 答题三层结构：先展示思维逻辑，再展开理论知识点，最后落到自己如何施展战略领导力

## 复习内容

- 核心概念与教材第 1、2、3、4、6 章框架
- 战略领导力四层次、制度设计、文化定位、系统思维与信任
- 四份新增课堂转写：10 月 31 日、11 月 14 日两份、11 月 15 日
- DAC、VUCA、知识与不确定性、学习型组织、德鲁克管理思想
- 思龙智能案例：治理结构、改革过程、团队流失、绩效评价与后续风险
- 论述题模拟、案例分析模拟及独立写作草稿
- 32 张记忆闪卡与考前速记
- 学习进度与草稿保存在当前浏览器

## 发布方式

进入仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存即可。

网站入口为根目录的 `index.html`，无需构建步骤或外部依赖。学习记录和草稿保存在当前浏览器的本地存储中。
